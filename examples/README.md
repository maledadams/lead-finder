# Examples

Not migrations. Nothing in here is applied by `pnpm run db:init`, and none of it
is needed to run this system.

`profile-medium-businesses.sql` is one real profile, kept as a worked example of
what a profile actually contains once it exists: three categories with their
OpenStreetMap tags, the email copy for each, a scoring brief, forty search terms
and forty cities.

You should not apply it. **Profiles are generated** — describe who you want to
reach in a sentence at first run, or in Settings afterwards, and all of the above
is written for your business rather than adapted from somebody else's. This file
is here to show the shape of the result, and as a reference if you ever want to
hand-write one.
